# AgriTriv 
**A MIPS Assembly Agricultural Trivia Game**

> "Educating the youth about agriculture, breaking the stigma, and promoting interest through interactive gameplay."

---

## 📖 About the Project
**AgriTriv** is a simple trivia game written in MIPS Assembly. It focuses on agricultural questions presented in a fun and engaging way.

**Purpose:**
This game aims to educate, especially the youth, about agriculture while promoting interest in the field and breaking the stigma often associated with it. The objective is to provide an enjoyable learning experience that increases awareness regarding crops, soil health, sustainability, and farming practices.

## Core Features
* **Progressive Difficulty:** Offers Easy, Medium, and Hard levels to suit different player skills.
* **Interactive Gameplay:** Engages players through multiple-choice questions requiring user input.
* **Score Tracking:** Tracks and displays the player’s score to encourage improvement.
* **Flexible Rounds:** Gives players the option to continue playing or exit after each round.
* **Educational Value:** Raises awareness and understanding of the agricultural sector.

---

## Technical Requirements
* **Language:** MIPS Assembly
* **Simulator:** MARS (MIPS Assembler and Runtime Simulator)

### How to Run
1.  **Download MARS:** https://computerscience.missouristate.edu/mars-mips-simulator.htm  
2.  Open MARS.
3.  Go to `File` -> `Open` and select `AgriTriv.asm`.
4.  Click `Run` -> `Assemble` (or press **F3**).
5.  Click `Run` -> `Go` (or press **F5**).
6.  Interact with the game via the "Run I/O" console at the bottom.
